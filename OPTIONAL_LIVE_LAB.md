# Live validation — deferred

**Live cloud validation: NO for AWS, Azure/Entra and GCP.** Both completed
milestones use public vendor schemas/examples and independent synthetic fixtures.
No account, tenant, billing, paid license or cloud credentials are required.

Live collection is outside the current scope. Any future live-validation milestone
would require a separately defined source, permitted actions, cost boundary and
provenance plan. Its evidence would be labeled `personally generated live event`,
separately from official documentation and synthetic scenarios. A small live
exercise could validate only the observed actions and would not establish
production administration experience or broad detection effectiveness.
